## HueBo

A simple HSB color selection app.

Requires Node.js 22.22.2 or newer in the 22 release line, 24.15.0 or newer in the 24 release line, or Node.js 26 or newer, and pnpm 12. Install dependencies with `pnpm install`, then run `pnpm start` for development. Run `pnpm checks` to run lint, tests, and the production build. The production build is written to `build`.

Set `REACT_APP_GOOGLE_ANALYTICS_ID` to configure Google Analytics. Dependencies must be at least three days old when resolved.
